┌──────────────────────────────────────┐

┌─────────────────────────────────────────────────────────────────────────┐
│                      COMPOSITION PIPELINE                               │
└─────────────────────────────────────────────────────────────────────────┘

Input: LayerStack with 3 layers
  │
  ├─ Layer 'background' (depth=0, visible=true)
  ├─ Layer 'sprite'     (depth=50, visible=true)
  └─ Layer 'ui'         (depth=100, visible=true)
  │
  ▼
┌─────────────────────────────────────┐
│ flatten-layers(stack, width, height)│
└─────────────────┬───────────────────┘
                  │
                  ▼
       ┌──────────────────────┐
       │ 1. Create blank      │
       │    canvas (spaces)   │
       └──────┬───────────────┘
              │
              ▼
       ┌──────────────────────────────────┐
       │ 2. Sort layers by depth          │
       │    (background → foreground)     │
       └──────┬───────────────────────────┘
              │
              ▼
       ┌──────────────────────────────────┐
       │ 3. For each visible layer:       │
       │    composite-transparent(        │
       │      dest=canvas,                │
       │      src=layer.canvas,           │
       │      offset=layer.offset)        │
       │                                  │
       │    Skip transparent cells (#\nul)│
       └──────┬───────────────────────────┘
              │
              ▼
       ┌──────────────────────┐
       │ 4. Return final      │
       │    composited canvas │
       └──────────────────────┘

┌─────────────────────────────────────────────────────────────────────────┐
│                    TRANSPARENCY MECHANISM                               │
└─────────────────────────────────────────────────────────────────────────┘

Transparent Character: #\nul (Unicode U+0000)

Source Canvas:              Destination Canvas:
┌─────────────┐            ┌─────────────┐
│ ∅ ∅ ∅ ∅ ∅ ∅ │            │ . . . . . . │
│ ∅ X X X ∅ ∅ │            │ . . . . . . │
│ ∅ X o X ∅ ∅ │  ───────▶  │ . X X X . . │
│ ∅ X X X ∅ ∅ │            │ . X o X . . │
│ ∅ ∅ ∅ ∅ ∅ ∅ │            │ . X X X . . │
└─────────────┘            │ . . . . . . │
                           └─────────────┘
∅ = transparent (#\nul)
X, o = opaque characters    Only opaque cells overwrite destination
. = background              Transparent cells preserve background
