THIMBLE EXAMPLES & DEMONSTRATIONS
═══════════════════════════════════════════════════════

Interactive examples and demonstrations of thimble/ features.

COMMAND SYSTEM
──────────────
  commands-example.ss          - Examples of custom commands
                                 Shows how to register and use commands

GRAPHICS & VISUAL
─────────────────
  demo-turtle.ss               - Turtle graphics demonstration
                                 Draw shapes using turtle commands

  graphics-primitives-demo.ss  - Graphics primitives showcase
                                 Lines, circles, rectangles, fills

STRING UTILITIES
────────────────
  string-utils-example.ss      - String manipulation examples
                                 split, join, trim, case conversion

PERFORMANCE & ANALYSIS
──────────────────────
  fuel-analysis-demo.ss        - Fuel consumption tracking
                                 Shows how to profile code

SCAFFOLDING
───────────
  scaffold-examples.ss         - Code generation examples
                                 Templates for common patterns

UNIVERSE & PERSISTENCE
──────────────────────
  universe-example.ss          - Universe (environment) examples
                                 State management patterns

WATCH SYSTEM
────────────
  watch-example.ss             - File watching demonstration
                                 Auto-reload on file changes

EXPERIMENTAL
────────────
  core-playground.ss           - Core function experimentation
                                 Interactive testing of core features
                                 (Created by Sauna during Deep Heat session)

USAGE
─────

Load and run examples in the REPL:
  (load "thimble/examples/demo-turtle.ss")
  (load "thimble/examples/graphics-primitives-demo.ss")

Or execute directly:
  scheme --script thimble/examples/string-utils-example.ss
