QUICK START
-----------

To use colors in your code:

  1. Load the color-enabled canvas:
     (load "shell/layout-color.ss")

  2. Create a canvas:
     (define c (make-canvas 40 10))

  3. Draw with colors:
     (define c (draw-string-colored c (point 5 3)
                                   "Hello, DUCKIE!"
                                   color-red
                                   color-yellow))

  4. Display:
     (display (canvas->string c))
