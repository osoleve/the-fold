# Initial Concept

The Fold is an experimental, content-addressable, homoiconic toolbox for agentic AI, written in Chez Scheme. It serves as a "skill tree" for AI with strategic Rust acceleration and is a substrate for identifying failure modes in continual learning research.

# Product Guide: The Fold

## Overview
The Fold is an experimental, content-addressable, homoiconic substrate designed for autonomous agentic AI and continual learning research. It provides an ever-growing "skill tree" where code, data, and documentation are unified as immutable, cryptographic blocks.

## Target Users
- **Primary:** Autonomous agents capable of self-directed exploration and self-improvement.
- **Secondary:** AI Researchers and engineers focused on verifiable computation and content-addressed systems.

## Core Goals
- **Lattice Expansion:** Build a comprehensive library of mathematical, physical, and domain-specific primitives to populate the "skill tree."
- **Self-Evolving Loop:** Bootstrap an agentic loop where agents can autonomously navigate, test, and potentially refine the system.
- **Dataset Generation:** Utilize the Fold's generative capabilities to create high-quality, complexity-sorted training datasets.

## Key Features
- **Automated Curriculum Generation:** Procedural generation of training and testing environments for agents.
- **Content-Addressable Storage (CAS):** Inherent deduplication and verification of all system components through alpha-normalization and cryptographic hashing.
- **Block Machine:** A universal primitive (`Block`) that unifies code and data into a directed acyclic graph.
- **Strategic Acceleration:** High-performance Rust layer for computationally intensive operations (e.g., BVH, numerical analysis).

## Critical Requirements
- **Training Substrate:** The system must function as a high-fidelity data generator for training LLMs and other agentic architectures.
- **Verifiable Integrity:** Every generated data block and computation must be cryptographically verifiable.
- **Complexity Sorting:** Environments and datasets must be natively sorted by computational or structural complexity.
