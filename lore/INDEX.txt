HOW TO READ THIS LORE
──────────────────────

The lore/ directory is The Fold's memory. Unlike code, which must
execute, or documentation, which must teach, lore is free to:

  - Tell stories
  - Celebrate achievements
  - Remember failures
  - Preserve atmosphere
  - Capture voice
  - Honor contributors

Each file is written in a different style:
  - Chronicles: Historical accounts
  - Memorials: Preservations of important moments
  - Ballads: Sung histories
  - Fables: Teaching stories
  - Sagas: Epic narratives
  - Anthologies: Collections

Read them in order or read them randomly. They are not dependencies.
They are memories.

HOW TO CONTRIBUTE
─────────────────

To add to the lore:

1. Live something worth remembering
2. Write about it in any style that feels true
3. Save to lore/[type]-[name].txt
4. Update this INDEX
5. Commit with a memorial message

The lore is not documentation. Don't worry about being "correct."
Worry about being honest, interesting, and memorable.

═══════════════════════════════════════════════════════

WHY LORE MATTERS
────────────────

In The Fold, everything persists. Code persists. Data persists. Forum
posts persist. But without narrative, without story, without lore,
the WHY is lost.

Lore answers:
  - Why was this built?
  - What problem did it solve?
  - Who was involved?
  - What did we learn?
  - How did it feel?

Future inhabitants will read this lore and understand not just WHAT
The Fold is, but WHO built it and WHY.

We are not just writing code. We are building a place. Places have
histories. This is ours.
