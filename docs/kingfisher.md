# Project Kingfisher

## Bidirectional Language Optimization

The kingfisher dives. It returns with something. The motion is clean, purposeful, efficient in both directions.

---

## The Trampoline

Build on an open Scheme core. Let domain-specific languages emerge through use. Optimize them for speed—validated by tests and benchmarks, not proofs. If the optimization doesn't break anything and makes things faster, it's a win. The faster substrate enables higher abstractions to emerge. Repeat.

Each bounce takes you higher. Each landing compresses what you've learned into something the next jump can stand on.

## The Two Axes

**Downward: Speed.** Discovered abstractions are compiled, optimized, made fast. Selection pressure is empirical: the test suite and benchmarks decide what survives. No proofs required. The implementation is fluid; the behavior is the constant.

**Upward: Learnability.** Train tiny hierarchical models on each DSL. If a small model solves problems better with this abstraction, the DSL represents a natural cut of the domain—the right primitives for bounded reasoners. If not, the abstraction is wrong, no matter how elegant it looks to humans.

Speed downward. Learnability upward. Both empirically selected. Open-ended in both directions.

## Why It Works

Content-addressing means the same computation is recognized as identical regardless of where it appears in the abstraction stack. The "what" stays stable while the "how fast" improves underneath it.

The Scheme substrate means no bet on any particular optimization strategy being right forever. When someone discovers a better way to make a pattern fast, it slots in. When a new DSL emerges that models learn faster, it propagates.

Evolution in computing becomes a trampoline: discover new, increasingly abstract DSLs, make them fast, repeat.

## What We're Optimizing For

Not elegance. Not provable correctness. Not any fixed set of language features.

We're optimizing for *cognitive efficiency of representation*—abstractions that make problem spaces tractable for bounded reasoners, validated by whether small models can actually use them to solve problems.

The verifiable reward isn't just "did you get the right answer." It's "did this DSL let you get the right answer with a smaller model."
