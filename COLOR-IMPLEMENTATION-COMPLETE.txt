API HIGHLIGHTS
==============

Color Construction:
  (rgb 255 128 64)              ; RGB truecolor
  (make-color-palette 42)       ; 256-color
  color-red, color-blue, etc.   ; Constants

Colored Drawing:
  (draw-char-colored c pt ch fg bg)
  (draw-string-colored c pt str fg bg)
  (fill-rect-colored c rect ch fg bg)
  (draw-box-colored c rect style fg bg)

DUCKIE Integration:
  (mood->color 'happy)          ; → Gold
  (energy->color 75)            ; → Yellow-ish

Color Helpers:
  (lerp-color c1 c2 t)          ; Interpolation
  (darken color 0.5)            ; Darken
  (lighten color 0.5)           ; Lighten

DESIGN PRINCIPLES
=================

1. Functional & Immutable
   - Pure functions only
   - No global state
   - Canvases remain immutable

2. Backward Compatible
   - layout.ss unchanged
   - Color is opt-in via layout-color.ss
   - Existing code works as-is

3. Expressive
   - Colors express emotion, not just decoration
   - Mood system maps feelings to hues
   - Energy gradients show vitality

4. Optimized
   - ANSI codes only when colors change
   - Minimal output size
   - Fast rendering (O(n) in canvas size)

USAGE EXAMPLE
=============

(load "shell/layout-color.ss")

;; Create canvas
(define c (make-canvas 50 12))

;; Draw DUCKIE in mood color
(define mood 'happy)
(define mood-color (mood->color mood))

(define c (draw-box-colored c
                           (make-rect (point 0 0) 50 12)
                           'double
                           mood-color
                           color-default))

(define c (draw-string-colored c (point 5 5)
                              "DUCKIE is happy!"
                              mood-color
                              color-default))

;; Display with ANSI colors
(display (canvas->string c))
